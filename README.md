# Full-Stack Chatbot Application

alph , A real-time interactive chatbot with Node.js , REST API backend and JavaScript frontend. Features keyword-based response matching and a clean, responsive chat interface.

## 🛠️ Technologies Used

- **Backend:** Node.js — backend runtime
Express.js — web server and /chat API endpoint
REST API / HTTP — communication between frontend and backend
OpenRouter API — connects your backend to the AI model
dotenv — securely loads your API key from .env

- **Frontend:** HTML5 — webpage structure/UI.
CSS3 — styling and responsive layout.
JavaScript — chat interaction, sending messages to the backend.
Marked.js — renders Markdown and properly formatted code blocks.

- **Architecture:** REST API

## ✨ Features
- Clean, mobile-friendly chat UI.
- REST API endpoint (`POST /api/chat`) for bot replies.
- Keyword-based response matching engine.
- Real-time message display.
- Persistent server running on localhost:3000
